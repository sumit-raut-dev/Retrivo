# Retrivo

A modern **Lost & Found Portal** that helps users report, search, and recover lost or found items efficiently. Retrivo provides a secure platform for managing lost belongings with authentication, claim verification, and an admin dashboard.

🌐 **Live Demo:** https://retrivo-frontend.onrender.com/

---

## Features

- 🔐 JWT Authentication & Google OAuth
- 📦 Report Lost & Found Items
- 🔍 Search and Filter Items
- 🤝 Claim Submission & Tracking
- 👤 User Dashboard
- 📊 Admin Dashboard & Statistics
- 📂 Category Management
- 📱 Fully Responsive Design
- 🔒 Role-Based Access Control

## ⚙️ Local Setup

```bash
# Clone the repository
git clone https://github.com/sumit-raut-dev/Retrivo.git

# Backend
cd retrivo-backend
dotnet restore
dotnet run

# Frontend
cd ../retrivo-frontend
npm install
ng serve
```

Open **http://localhost:4200**
